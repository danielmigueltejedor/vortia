# Regional mesh controls and real previews

Mesh settings accept up to 32 internal straight cuts with two X/Y endpoints in millimetres. Endpoints can snap to the CAD contour or existing cuts; coordinates remain editable. The external Sketch2D contour and its boundary conditions are unchanged. OpenCASCADE fragments the actual line/arc surface and revolves all resulting faces together. Adjacent regions share conformal interfaces; cuts never become wall patches. See the [Gmsh manual](https://gmsh.info/doc/texinfo/gmsh.html) for `occ.fragment` and restricted size fields.

Each detected region has a persistent seed, name, target cell size and triangle/quad-dominant method. Size fields apply to each face and its shared edges; the global near-wall field can further refine cells. Neighboring counts can change when interfaces need finer resolution. Quad-dominant is not a mapped all-quad guarantee. Quad columns touching the rotation axis at an odd number of vertices are split into conformal triangle columns (pyramids/tetrahedra) before MSH export, avoiding unsupported seven-vertex solids.

Changing or removing cuts archives current regional controls for recovery onto new faces. Unmatched controls are retained and shown through Recover saved region settings. Ambiguous face matches must be reviewed through preview before final generation. Mesh settings, cuts and seeds are saved in flow-setup.json; changing geometry can require updating endpoints and reviewing associations. These are absolute-coordinate mesh partitions, not persistent CAD dimensional constraints.

Preview runs the actual mesher in an isolated temporary subprocess and does not require flow boundary values, OpenFOAM execution or CFD fields. Its pipeline, cell connectivity and deterministic seed are shared with final mesh generation. The 2D axial/radial section displays the actual cells of the revolved one-layer wedge. Navigation uses the same pinch/wheel/pan camera as boundary previews. Settings changes visibly mark previous cells stale. A preview result arriving for an older revision is discarded. Cancel and close terminate the subprocess and preserve projects/cases.

Preview is limited to 200,000 cells; final generation permits 1,000,000 cells. There is an early regional resolution estimate and the actual limit is checked after generation. No coarsened illustration is substituted for an oversized mesh. Final conversion rejects unassigned faces; OpenFOAM checkMesh remains part of the existing workflow before flow calculation. Mesh validity does not establish CFD convergence or physical validation.

The tutorial's partition sequence at approximately 03:30–03:55 separates the nozzle interior at the mouth and splits the exterior along the projected divergent-wall direction. This release supplies general tools to reproduce that topology on arbitrary sketches. Demonstration sizes are explicitly separate from tutorial settings and mesh-independence requirements; no special practice-only screen is introduced.

Shared-vertex cuts can cause OCC revolve output tags to omit volumes that are present in its synchronized model. Region/volume pairing therefore uses the complete model topology and checks a one-to-one front-face mapping. The native regression `resources/flow/test_mesh_regions_native.py` exercises rounded oblique cuts, reversed endpoints, 5°/0.1° wedges, local size/method editing and exact preview/export parity. CI converts the exported meshes and runs full OpenFOAM topology/geometry checks.

A completed cut returns to selection. Mesher failure keeps cuts editable and shows a short message with a collapsed, bounded technical log; retry clears that log.
