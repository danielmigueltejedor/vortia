# Sketch editing, references and boundary lineage

Cmd/Ctrl+Z undoes geometry edits; Cmd/Ctrl+Shift+Z redoes them. Each project tab retains its own undo/redo stack, limited to 64 edits. A vertex drag forms one edit. Standard text controls retain their text editing shortcuts. Delete/Backspace on the canvas or vertex table removes the selected vertex; incident segments are replaced by a straight join and unrelated arcs remain. Geometry edits invalidate the prepared mesh fingerprint; earlier cases remain intact.

Cmd/Ctrl+C copies a selected vertex, a selected line/arc, or the whole sketch with no selection. Cmd/Ctrl+V validates the geometry clipboard and asks for X/Y placement offsets in millimetres. An empty destination retains a copied closed profile and arcs. An open profile appends/connects an open fragment. Multiple independent contours and appending a second closed profile are not supported; these cases leave the original geometry intact.

Drawing references are individually enabled: endpoints, midpoints, arc centers, vertex alignments, perpendicular tracking, orthogonal mode and 15-degree polar tracking. F3 enables references, F8 toggles orthogonal, F10 toggles polar. Shift temporarily constrains to horizontal/vertical; Alt suspends references. Geometry references take precedence over the optional grid. Screen-distance tolerance remains 10 pixels across zoom levels. The preview shows the actual candidate, guide lines, length and angle; a click commits that same placement. Clicking the first endpoint closes an eligible open profile. These are placement aids, not persistent parametric constraints.

Placed vertices can be edited by double-clicking X/Y in the table, by changing the selected coordinates (applied when editing finishes), or by double-clicking a canvas vertex / pressing Enter. Tangent-support vertices remain protected: edit their arc radius instead. Fillet dialogs use feasible geometric radius intervals so impossible default radii are not proposed. Invalid moves retain the original vertex and report inline feedback.

The boundary editor shows a numbered geometric preview linked to its rows, endpoints and segment lengths/radii. Existing regions can be applied to selected rows. Unchanged, trimmed and split segments inherit existing boundary conditions. A new tangent arc between two walls inherits wall physics; differing wall names receive a separate rounded-wall name. Ambiguous mixed-type arcs/joins are explicitly unassigned, and their earlier settings remain available for recovery. Vertex moves and supported radius changes retain topology. Geometry undo restores cached boundary associations; 64 geometry snapshots are retained. Legacy count mismatches can recover their reference geometry from the retained prepared case.

A straight segment on Y=0 is Axis. Invalid OpenFOAM region names are normalized; identical names with conflicting physical settings are separated without changing inlet/outlet pressures or temperatures. Ignored wall/axis scalar values are canonicalized. Safe control repairs clamp output interval to the iteration limit, wall cell size to global cell size, and minimum acceptance iterations to the check interval. Geometry metadata is excluded from the physical fingerprint. Unresolved boundary types and missing inlet/outlet assignments are directed back to the editor before mesh generation. Physical quantities such as Cp, chamber pressure, temperature and turbulence parameters are never guessed to suppress errors.
