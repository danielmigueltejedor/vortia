# Fonts

The typefaces the Nodalia Design Language names, bundled so Vortia looks the same where neither is installed. Both are the unmodified variable fonts from the google/fonts repository, under the SIL Open Font License 1.1 (each licence is beside its font). Reserved font names apply: do not rename or modify them.

| Font | Use | Source |
| --- | --- | --- |
| Sora | Titles | https://github.com/google/fonts/tree/main/ofl/sora |
| Inter | Interface text | https://github.com/google/fonts/tree/main/ofl/inter |

Copied from nodalia-design `packages/fonts/`.
